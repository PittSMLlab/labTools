AddPythonData

PURPOSE

% Add Python biofeedback data to adaptData

SYNOPSIS

This is a script file.

DESCRIPTION 

% Add Python biofeedback data to adaptData
 Script. Processes Python biofeedback data files and appends their
 columns to the end of a subject's adaptData. Nexus processing must
 already be done, or the labTools objects cannot be found. Meant for any
 study that collects biofeedback together with a Nexus gait trial, not
 for biofeedback outside gait.

 Inputs:
   none - the subject file, subject code, Python files, trial
          assignment, and variables to add are requested during the run

 Outputs:
   none - a message in the command window reports success or failure

 Side effects: changes the current folder to the selected subject
   folder; loads <ID>RAW.mat, <ID>.mat, and <ID>params.mat; opens
   dialogs, tables, and diagnostic figures; leaves many variables in the
   base workspace; silently overwrites <ID>params.mat (not -v7.3) in the
   selected subject folder with the extended adaptData (see
   DATA_OUTPUTS.md).

 Toolbox Dependencies: Signal Processing Toolbox

 See also SYNCPYTHON_FORSTATIC.

CROSS-REFERENCE INFORMATION

This function calls:
  • isempty ISEMPTY Checks if the date equals the default value.
  • adaptationData
  • cell2mat CELL2MAT Converts cell array of strideData to matrix.
  • plot PLOT Plots aligned data with mean.
  • getDataAsVector GETDATAASVECTOR Extract data vectors for the specified label(s).
  • plot PLOT Plots data in subplots.
  • resample RESAMPLE Resamples timeseries to different sampling period.
  • resample RESAMPLE Resamples (override).
  • parameterSeries
  • plot PLOT Plots every cluster as a bar graph of its mean synergy.
  • plot PLOT Plots a 1-D SynergySetCollection, one row of subplots per set.
  • getEventsFromForces GETEVENTSFROMFORCES Detect gait events from vertical GRF signals.
  • JSONtxt2cell JSONTXT2CELL Parse a JSON text file into a header and numeric matrix.
