GetInfoGUI

PURPOSE

GetInfoGUI GUI for collecting experimental session information.

SYNOPSIS

function varargout = GetInfoGUI(varargin)

DESCRIPTION 

 GetInfoGUI  GUI for collecting experimental session information.

   Launches a graphical user interface to gather all information regarding
 a single experiment conducted in the Sensorimotor Learning Laboratory.
 Fields include participant demographics, experiment metadata, data file
 locations, trial and condition assignments, and EMG channel labels. Refer
 to in-GUI help text (hover over any field) for field-specific guidance.

   Side effects: saves <ID>info.mat to the chosen save folder (asks
 before reusing an existing ID) and, from the Save As button, a new
 experiment description .mat in importc3d/ExpDetails (see
 DATA_OUTPUTS.md).

   Outputs:
     info - Struct containing all session information entered by the user,
            or empty ([]) if the GUI was closed without saving.

   Toolbox Dependencies:
     None

   See also: errorProofInfo, importc3d/ExpDetails

0164     save(infoSavePath, 'info');
0165 
0166     % Prompt user for individual trial observations

0168         'Are there any observations for individual trials? (y/n): ', 's');
0169

1489 % --- Executes on button press in saveExpButton.
1490 function saveExpButton_Callback(hObject, eventdata, handles)
1491 % saveExpButton_Callback  Saves the current condition configuration as
1492 %   a new experiment description file in the ExpDetails directory
1493 %   (prompts before overwriting a file of the same name).
1494 %
1495 %   Inputs:
1496 %     hObject   - handle to saveExpButton (see GCBO)
1497 %     eventdata - reserved for future MATLAB versions
1498 %     handles   - struct with handles and user data (see GUIDATA)
1499 
1500 % Build the expDes structure from current GUI field values
1501 nConds = 0;
1502 for ii = 1:handles.lines
1503     % Condition numbers
1504     condNum = get(handles.(['condition' num2str(ii)]), 'String');
1505     if ~isempty(condNum)
1506         expDes.(['condition' num2str(ii)]) = condNum;
1507         nConds = nConds + 1;
1508     end
1509     % Condition names
1510     condName = get(handles.(['condName' num2str(ii)]), 'String');
1511     if ~isempty(condName)
1512         expDes.(['condName' num2str(ii)]) = condName;
1513     end
1514     % Condition descriptions
1515     condDesc = get(handles.(['description' num2str(ii)]), 'String');
1516     if ~isempty(condDesc)
1517         expDes.(['description' num2str(ii)]) = condDesc;
1518     end
1519     % Trial numbers for each condition
1520     trialNum = get(handles.(['trialnum' num2str(ii)]), 'String');
1521     if ~isempty(trialNum)
1522         expDes.(['trialnum' num2str(ii)]) = trialNum;
1523     end
1524     % Trial types
1525     type = get(handles.(['type' num2str(ii)]), 'String');
1526     if ~isempty(type)
1527         expDes.(['type' num2str(ii)]) = type;
1528     end
1529 end
1530 expDes.numofconds = nConds;
1531 
1532 answer = inputdlg( ...
1533     'Enter name of new experiment description: ', ...
1534     'Experiment Description Name');
1535 if ~isempty(answer)
1536     answer = char(answer);
1537     expDes.group = answer;
1538     % Remove non-alphanumeric characters from the filename
1539     answer = answer(ismember(answer, ['A':'Z' 'a':'z' '0':'9']));
1540     detailsPath = which('GetInfoGUI');
1541     detailsPath = strrep(detailsPath, 'GetInfoGUI.m', 'ExpDetails');
1542     if isfile(fullfile(detailsPath, [answer '.mat']))
1543         choice = questdlg( ...
1544             'File name already exists. Overwrite?', ...
1545             'File Name Warning', 'Yes', 'No', 'No');
1546         if strcmp(choice, 'No')
1547             h = msgbox('Experiment description was not saved.', '');
1548             waitfor(h);
1549             return;
1550         end
1551     end
1552     save(fullfile(detailsPath, answer), 'expDes');
1553     description_edit_CreateFcn(handles.description_edit, ...
1554         eventdata, handles);
1555     newContents = get(handles.description_edit, 'String');
1556     ind = find(ismember(newContents, answer));
1557     set(handles.description_edit, 'Value', ind);
1558 end
