ReviewEventsGUI

PURPOSE

REVIEWEVENTSGUI Plot and edit gait events in an experimentData object.

SYNOPSIS

function varargout = ReviewEventsGUI(varargin)

DESCRIPTION 

REVIEWEVENTSGUI Plot and edit gait events in an experimentData object.

   Loads a saved experimentData MAT file and provides an interactive
 interface to review force-plate and kinematic gait events (HS, TO),
 add or delete individual events, label strides as good or bad, and
 save the updated experimentData back to disk.

 Toolbox Dependencies:
   None

 See also: experimentData, calcParameters, labTimeSeries

0792 %DELETE_BUTTON_CALLBACK Delete the events nearest to mouse clicks.
0793 %
0794 %   Reads clicks on the top axes with ginput (finish with return) and clears
0795 % the event(s) within 1 s of each click. Recomputes the parameters of the
0796 % trial with calcParameters, which discards manual stride label edits, and
0797 % replots.
0798 %
0799 % Inputs:
0800 %   hObject   - handle to the control that triggered the callback
0801 %   eventdata - reserved for future MATLAB versions
0802 %   handles   - struct with handles and user data (see GUIDATA)

0808 global expData
0809 
0810 axes(handles.axes1)
0811 [x, ~] = ginput;
0812 
0813 allEventsIndexes = find(sum(handles.trialEvents.Data, 2) > 0);
0814 minDeltaTThresh  = 1;     % events within 1 s of click are candidates (s)
0815 % pad to also catch simultaneous alt-class event (s)

0817 for ii = 1:length(x)
0818     deltaT    = handles.trialEvents.Time(allEventsIndexes) - x(ii);
0819     minDeltaT = min(abs(deltaT));

0824     end

0828 % NOTE: recalculating parameters here undoes any manual stride label edits
0829 expData.data{handles.idx}.adaptParams = calcParameters( ...
0830     expData.data{handles.idx}, expData.subData);
