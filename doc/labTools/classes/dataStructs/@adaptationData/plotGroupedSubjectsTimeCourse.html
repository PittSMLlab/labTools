 Inputs:
   adaptDataList       - subject file names (see PLOTGROUPEDSUBJECTSBARS)

   condList            - conditions to plot
   earlyNumber         - strides in the early set
   lateNumber          - strides in the late set
   exemptLast          - strides skipped at the end
