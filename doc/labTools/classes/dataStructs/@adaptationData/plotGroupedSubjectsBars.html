plotGroupedSubjectsBars

PURPOSE

PLOTGROUPEDSUBJECTSBARS Bar plot of early/late parameter means by group.

SYNOPSIS

function [figHandle,allData] = plotGroupedSubjectsBars(adaptDataList,label,removeBiasFlag,plotIndividualsFlag,condList,earlyNumber,lateNumber,exemptLast,legendNames,significanceThreshold,plotHandles,colors)

DESCRIPTION 

PLOTGROUPEDSUBJECTSBARS Bar plot of early/late parameter means by group.

   Deprecated (warns on every call): use PLOTGROUPEDSUBJECTSBARSV2. For
 each label, plots the mean over subjects of the first N1 (very early),
 first N2 (early) and last N3 (late) strides of each condition, groups
 side by side, with optional individual subjects and between-group
 significance bars. Subjects are loaded from the .mat files named in
 adaptDataList.

 Inputs:
   adaptDataList         - char (one subject), cell array of subject
                           file names (one group), or cell array of
                           such cell arrays (several groups)
   label                 - cell array of parameter labels, one subplot
                           each
   removeBiasFlag        - passed to GETGROUPEDDATA
   plotIndividualsFlag   - plot each subject (default true)
   condList              - conditions to plot (default: all named
                           conditions of the first subject)
   earlyNumber           - strides in the early bars (default 5)
   lateNumber            - strides in the late bars (default 20)
   exemptLast            - strides skipped at the end (default 5)
   legendNames           - group names for the legend (default:
                           adaptDataList)
   significanceThreshold - p-value threshold for the significance bars
                           (default []: none)
   plotHandles           - axes handles, one per label (default: new
                           figure)
   colors                - Nx3 group colors, N > number of groups

 Outputs:
   figHandle - figure handle
   allData   - cell array, one struct per label, with fields early,
               late, veryEarly, subIDs, group{} and parameterLabel

 Toolbox Dependencies: Statistics and Machine Learning Toolbox

 See also PLOTGROUPEDSUBJECTSBARSV2, GETGROUPEDDATA.
