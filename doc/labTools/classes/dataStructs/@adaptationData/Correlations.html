Correlations

PURPOSE

CORRELATIONS Plot linear correlations between conditions or parameters.

SYNOPSIS

function Correlations(adapDataList, results, params, conds, groups,colorOrder, type)

DESCRIPTION 

CORRELATIONS Plot linear correlations between conditions or parameters.

   Draws one subplot per parameter (type 1) or per condition (type 2),
 with one dot per subject colored by group, a linear fit, and the
 Pearson r (and its p-value) as text. Also sets the figure renderer to
 'painters'.

 NOTE: clearvars removes every variable except the ones named in its
 -except list, so locals are cleared when the figure is complete.

 Inputs:
   adapDataList - unused
   results      - struct with, per condition, indiv.<param> = [group
                  index, value] per subject
   params       - cell array of parameter names
   conds        - cell array of condition names
   groups       - cell array of group names (for the legend)
   colorOrder   - (optional) Nx3 group colors; defaults to the
                  poster_colors palette
   type         - 1: per parameter, conds{2} vs conds{1};
                  2: per condition, params{2} vs params{1}

 Outputs:
   none (draws in the current figure)

 Toolbox Dependencies: Statistics and Machine Learning Toolbox

 See also FITLM, CORR, OPTIMIZEDSUBPLOT, POSTER_COLORS.
