parameterTimeCourse

PURPOSE

PARAMETERTIMECOURSE Plots parameter time course

SYNOPSIS

function [h, adaptDataObject] = parameterTimeCourse(this, field)

DESCRIPTION 

PARAMETERTIMECOURSE Plots parameter time course

   [h, adaptDataObject] = parameterTimeCourse(this, field) creates a plot
 showing the specified parameter over time/strides

 NOTE: This function takes a long time to run. For efficiency, generate and
   save an adaptData object, then use its plotting functions directly.

 Inputs:
   this  - experimentData object
   field - parameter label to plot

 Outputs:
   h               - figure handle
   adaptDataObject - adaptationData object used for plotting

 Toolbox Dependencies: None

 See also PARAMETEREVOLUTIONPLOT, ADAPTATIONDATA.PLOTPARAMTIMECOURSE.
