sortConditions

PURPOSE

SORTCONDITIONS Sorts conditions by trial order.

SYNOPSIS

function newThis = sortConditions(this)

DESCRIPTION 

SORTCONDITIONS Sorts conditions by trial order.

 their trial numbers, from earliest to latest
