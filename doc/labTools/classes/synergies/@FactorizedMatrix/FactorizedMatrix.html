0003     %
0004     %   Represents a matrix H (MxN) as H_ij = sum_k u_ki v_kj, with k in
0005     % [1:p], p < M and p < N. The factorization is exact only if rank(H) <=
0006     % p. Both vector sets are indexed with the reduced dimension first: u_ki
0007     % is stored as dim1Vectors and v_kj as dim2Vectors. Tensors are also
0008     % supported, as H_ijl = sum_k u_ki v_kjl, where the v are tensors with
0009     % one dimension fewer than H.
0010     %
0011     % FactorizedMatrix properties:
0012     %   dim1Vectors         - first factor, reduced dimension first
0013     %   dim2Vectors         - second factor, reduced dimension first
0014     %   name                - display name (default 'Unnamed')
0015     %   factorizationMethod - method that produced the factors
0016     %   originalDimension   - lesser of M and N (dependent)
0017     %   matrixSize          - size of the factorized matrix (dependent)
0018     %   reducedDimension    - p, the number of factors (dependent)
0019     %   factorizedMatrix    - product of the factors (dependent)
0020     %   paramCount          - number of parameters in the factors
